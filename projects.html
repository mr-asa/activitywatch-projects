    How do I track a new project?

    1. Add a project and choose its color.

    2. Add a rule. Choose Window title or Browser URL, then Plain text or Regex. Use Preview matches to check the current report.

    3. Set dates when needed. Valid from and Valid through limit that individual rule to local calendar dates. End dates are inclusive. Blank dates mean no limit.

    For a reused chat title, end the old project's rule before the new project's rule begins. Identical chat titles used simultaneously need manual assignment.

    Assign interval overrides automatic matching for recorded active time within that interval only. Double-click a timeline segment or use Assign time only on an unassigned activity. Remove an override under Manual assignments to restore automatic matching.

    Regex uses JavaScript syntax without / delimiters. It matches original titles; plain text retains the existing [modified] handling.

    Rules and colors apply on this Projects page. ActivityWatch's standard Summary uses separate categories.
