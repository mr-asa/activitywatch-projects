## Workload chart

- Hover a legend entry to bring that project or tag forward; everything else fades.
- Project and tag chips: close a chip to hide it, "+ add" to bring it back; All / Custom / None popups.
- New Stacked bars view and a "100% of the day" checkbox for both Lines and Bars.
- Thinner lines; the view settings sit right above the chart.
- Removed the "All active time", "All project work" and "Non-project %" checkboxes (the values stay in the legend).

## Attribution

- Overlaps shorter than one second between a window title and a page URL (tab switches) no longer land in "Needs review"; they count as not assigned.

## Update

- The Update button launches `awprojects://` from the top window, so the frame is no longer blanked.
