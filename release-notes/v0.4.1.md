## Period bar

- "Today lock": the last day of the period always follows today. Available for Day, Week, Month and Custom range; Week and Month start relative to today, and the locked dates are greyed out.
- Week, Month and Custom range now show their first and last day; Day shows one date.
- The Daily workload chart has its own Today lock with the same rules.

## CI

- Release and test workflows run on Ubuntu 24.04 (Playwright does not support Ubuntu 26.04), so 0.4.0 was never published; this release replaces it.
